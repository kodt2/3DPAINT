# ADR 0002: Strangler pattern — Gateway перед монолитом, сервисы по одному

- **Статус:** принято (2026-11-22, формализация)

## Контекст

Приложение рабочее, нельзя «переписать за выходные». Нужен путь, при котором
система остаётся рабочей после каждого шага.

## Решение

1. Перед монолитом ставится API Gateway (YARP); монолит временно служит
   fallback для всех маршрутов.
2. Сервисы (Auth, Models, Processing, AI) выделяются по одному: сначала
   новый сервис живёт параллельно, затем трафик переключается на Gateway,
   затем старый код удаляется только после подтверждения человека.

## Последствия

- Плюс: каждый шаг обратим, регрессии видны сразу, старые пути остаются
   рабочими до явного удаления.
- Минус: временный период, когда два кода делают одно и то же; нужен порядок
   переключения (описан в `IMPLEMENTATION_PLAN.md`).
