# ADR 0003: Прямая загрузка в S3-хранилище по presigned URL

- **Статус:** принято (2026-11-22, формализация; уточнение по реализации S3 — ADR 0009)

## Контекст

Файлы до сотен МБ. Прогонять их через веб-сервис — лишний RAM (сейчас
монолит буферизирует multipart в памяти, TD-13), нагрузка на сеть и на один
процесс.

## Решение

Браузер получает presigned URL из сервиса (Auth/Models), грузит файл
**напрямую** в S3-хранилище и сообщает сервису о завершении. Сервисы не
транзитируют содержимое файлов.

## Последствия

- Плюс: сервисы не держат крупные данные в памяти; масштабирование загрузки
  не зависит от сервисов.
- Минус: нужен публично достижимый endpoint хранилища (в dev — ограничение
  внутренней сети, TD-3; в проде решается reverse proxy / CDN).
