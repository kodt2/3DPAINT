# ADR 0004: RabbitMQ + MassTransit, raw JSON для Python-очередей

- **Статус:** принято (2026-11-22, формализация)

## Контекст

Нужна асинхронная связь между сервисами (.NET и Python). Долгие операции
(обработка, AI) не могут быть синхронными HTTP-вызовами.

## Решение

- Очередь: RabbitMQ.
- .NET: MassTransit (Outbox, retry, DLQ из коробки).
- Python: `aio-pika`, сообщения — plain JSON (без специфичных форматов .NET),
  контракты — JSON Schema в `contracts/events/`.

## Последствия

- Плюс: зрелые механизмы доставки, идемпотентные консьюмеры, DLQ;
  Python не тащит .NET-зависимости.
- Минус: ещё один инфраструктурный сервис; дисциплина контрактов событий
  обязательна (схема — источник истины).
