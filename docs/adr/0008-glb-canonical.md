# ADR 0008: GLB — единый формат отдачи в браузер

- **Статус:** принято (2026-11-22, формализация)

## Контекст

Пользователи могут загружать разные форматы (STL, OBJ, STEP, GLB, …).
Поддерживать все форматы в Three.js-вьювере невозможно/нецелесообразно.

## Решение

Оригинальный файл хранится как есть (S3). Processing Service конвертирует
его в **GLB** (единый канонический формат для браузера) + превью (WebP).
Браузеру всегда отдаётся GLB/превью, а не исходный файл.

## Последствия

- Плюс: один формат в вьювере (Three.js нативно читает GLB), предсказуемые
  размеры и структура.
- Минус: форматы без прямой конвертации (напр. STEP) требуют отдельного
  инструмента в Processing; часть информации исходного формата теряется в
  GLB.
