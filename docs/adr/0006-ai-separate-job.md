# ADR 0006: AI запускается отдельной задачей из Models, не цепочкой из Processing

- **Статус:** принято (2026-11-22, формализация)

## Контекст

AI-задачи (генерация текстур и т.п.) долгие, ресурсоёмкие (GPU) и не всегда
необходимы для базовой обработки модели. Привязывать их к конвейеру
Processing — лишняя жёсткая зависимость.

## Решение

AI-задача — отдельный тип работы: Model Service публикует `AiJobRequested`
отдельным действием пользователя; AI Service сам читает входные данные из
S3, сам публикует результат (`AiJobCompleted`/`AiJobFailed`), Models
применяет его к статусу модели.

## Последствия

- Плюс: независимое масштабирование (в т.ч. GPU), долгая AI-работа не
  блокирует обработку моделей.
- Минус: на одну модель — два независимых конвейера, статусы нужно
  показывать отдельно (`Status` и `AiJobStatus`).
