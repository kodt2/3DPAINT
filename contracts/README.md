# contracts/

Контракты событий и API — источник истины для всех сервисов.

- `events/` — JSON Schema событий (создаётся на Фазе 2, шаг 2a).
- `dotnet/` — C#-записи (`ThreePaint.Contracts`), синхронизированы со схемами (Фаза 2, шаг 2b).
- Python-модели (pydantic) живут в сервисах и генерируются/проверяются по JSON Schema.
